# 弯兔 / onetwo 品牌基线

## 核心定位

把日常照片玩成有创意、有情绪的作品。

## 品牌名称

- 中文：弯兔
- 英文：onetwo
- 名称含义："弯"代表不按常规、带一点俏皮的创作；"兔"是可亲近、容易记住的角色锚点；onetwo 读起来轻快，也呼应“玩图”。

## 图标

- 主图标：`assets/brand/wantu-app-icon-v1.png`
- 特征：歪头、弯耳、夸张侧倾的兔子；用一个动作表达“弯兔”。
- 使用原则：保持完整黄色圆角底和深蓝兔子轮廓；不叠加阴影、渐变、文字或额外装饰。

## 色彩

- 弯兔黄：`#FFE25A`
- 深墨蓝：`#132C62`
- 页面底色可使用弯兔黄的极浅色调，但核心按钮、图标和标题只使用这两种品牌色。

## 文案

- 主宣传语：一弯，就有趣
- 备选：把照片，玩成作品

## 后续 UI 原则

1. 黄色用于情绪和主行动，深蓝用于信息与结构。
2. 保持大色块、圆润轮廓和轻松不对称；避免卡片堆叠与过度装饰。
3. 弯兔以“从边缘探头”“歪头出现”等小动作参与页面，而不是重复摆放成贴纸。
